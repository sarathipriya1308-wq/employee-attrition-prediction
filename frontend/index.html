ABOUT THE PROJECT

A practical ML project built around a real business problem.

Employee attrition is a common challenge for organizations. PeopleSignal demonstrates how machine learning can transform employee-level information into an understandable attrition risk signal.

The application uses a Python machine learning pipeline served through Flask and connected to a responsive browser interface.
